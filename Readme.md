 ### คำสั่ง Shutdown และ Reboot บน Linux
 
***Restart Restart Command***

##### ทำการรีบูทเครื่องทันที
*#shutdown -r now*

##### ทำการรีบูทเครื่องในอีก 5 นาทีข้างหน้า
*#shutdown -r +5*

##### ทำการรีบูทเครื่องทันที
*#reboot*

หรือ

*#init 6*
