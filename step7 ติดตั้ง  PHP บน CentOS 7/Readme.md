####  วิธีติดตั้ง  PHP บน CentOS 7   

เว็บเซิร์ฟเวอร์ที่ได้จาก ติดตั้งและคอนฟิกเว็บเซิร์ฟเวอร์ Apache บน CentOS 7 เบื้องต้น จะรองรับไฟล์เว็บ .html ธรรมดาเท่านั้น ไม่สามารถเขียนเว็บโปรแกรมเพื่อประมวลผลบนเซิร์ฟเวอร์ก่อนแสดงผลได้ (Server-side scripting)
หากต้องการเขียนโปรแกรมเช่น php ต้องติดตั้งโมดูล (Apache Module) เพื่อโหลดในเว็บเซิร์ฟเวอร์เพิ่มเติม

------------
#### ขั้นตอนที่ 1 ตรวจสอบแพ็กเกจ  PHP  ว่าติดตั้งแล้วยัง 

ใน CentOS หรือ RedHat  จะใช้ชื่อแพ็กเกจ yum หรือชื่อเซอร์วิสของ PHP  ว่า php


#### 1.1\. ก่อนการติดตั้งซอฟต์แวร์ใหม่ ควรทำการอัปเดตระบบเสมอ 
*#yum -y updat*      ⏪⏪⏪  


ใช้คำสั่งตรวจสอบ packet http ว่า ติดตั้งแล้วยัง ให้พิมพ์ คำสั่ง 
*#rpm -q httpd*      ⏪⏪⏪  ***ถ้ายัง ให้ติดตั้ง packet http***

#### 1.2\. ทดสอบการเชื่อมต่อ internet  
ใช้คำสั่งทดสอบการเชื่อมต่อ internet  
*#ping 8.8.8.8*  ⏪⏪⏪  ***ใช้ ctrl-c ออกจากคำสั่ง***

#### 1.3\. ทำการ start service  httpd 
ใช้คำสั่ง ทำการ start service httpd

*#systemctl restart httpd*  ⏪⏪⏪  

------------
#### ขั้นตอนที่ 2 สร้างไฟล์ php ขึ้นมาทดสอบ  

วิธีการทดสอบที่นิยมกันมากที่สุดก็คือใช้ฟังก์ชัน phpinfo() เพื่อแสดงข้อมูลรายละเอียดของ php ทั้งหมดที่ติดตั้งไว้ 

#### ทดลอง เขียน Script php  
เขียน Script html ที่ Directory  /var/www/html/ ⏪⏪⏪  ***ตำแหน่งที่อยู่ ไฟล์ ***

/var/www/html/ ⏪⏪⏪  ***ตำแหน่งที่อยู่ ไฟล์ ***


ใช้คำสั่ง   
*#cd  /var/www/html/*
*#nano test.php*  		⏪⏪⏪  ***ชื่อไฟล์ .php*** 

เขียน Script ดังนี้ 

*< ?php*

*phpinfo() ;*

*?>*
